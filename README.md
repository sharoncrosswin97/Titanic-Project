Titanic Survival Data Analysis – Python Project
This project explores the Titanic dataset using Python for data cleaning, exploration, and visualization. The objective was to identify key factors that influenced survival rates among passengers.

🔍 Key Focus Areas:
Cleaned missing values (like age and embarked)

Analyzed survival based on gender, passenger class, age, and embarked port

Used groupby, pivot tables, and visualizations to uncover patterns

Created insightful plots using Matplotlib and Seaborn

🛠️ Tools Used:
Python (Pandas, NumPy, Seaborn, Matplotlib)

Jupyter Notebook

This analysis provided clear insights on how class and gender impacted survival, and helped visualize demographic patterns across the dataset.# Titanic-Project
